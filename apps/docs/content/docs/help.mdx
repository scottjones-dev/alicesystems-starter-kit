## Quick checks

<Accordions>
  <Accordion title="My sign-in link did not arrive">
    Check your spam folder and that you typed the address correctly, then ask for a new link.
  </Accordion>
  <Accordion title="My sign-in link says it expired">
    Links work once and expire after a short time. Ask for a new one and open it straight away, on
    the device you are signing in on.
  </Accordion>
  <Accordion title="The text is in the wrong language">
    See [Language and appearance](/docs/language-and-appearance) for how the language is chosen.
  </Accordion>
  <Accordion title="Something looks broken">
    Check the **service status** in the website footer. If everything is running, refresh the page
    and try again.
  </Accordion>
</Accordions>

## Contact us

Email the support address on the [website](/docs/website). Tell us:

- what you were trying to do,
- what happened instead,
- the device and browser or app you used.

Never send your password. We will never ask for it.
