The website is the public face of the product. You do not need an account to visit it.

## What you can do there

- Read what the product is and who it is for.
- Find the **terms** and **privacy** pages.
- Find the support address.
- Check the **service status** in the footer, which shows whether everything is running normally.

<Callout title="Coming soon">
  Pricing and sign-up pages arrive with the first release. This page will explain them then.
</Callout>

## Signing in

Sign-in happens in the [web app](/docs/web-app), not on the website. It is not available yet.

## Using it on a phone

The website works on any screen size. For daily work on a phone or tablet, use the [mobile app](/docs/mobile-app).
