## Adding a page

Pages are Markdown or MDX files in `docs/content/docs`. Every page needs a `title` and `description` in its frontmatter.

- A file such as `packages/env.md` becomes `/docs/packages/env`.
- A folder groups pages. Add a `meta.json` inside it with a `title` and a `pages` list to control the sidebar order.
- Use `"---Heading---"` in a `pages` list to add a separator label.

Each package documents a **plan** (requirements, design, trade-offs) so the reasoning survives after the code is written.
