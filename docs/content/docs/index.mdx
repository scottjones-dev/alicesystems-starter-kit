StarterKit is a reusable monorepo: a Next.js website, an Expo mobile app and a Hono API, with accounts, Postgres, translations, emails, analytics, error reporting and file storage already wired together. You start a product by copying it and building your own features on top.

These docs are for the developers working in it. Each page explains **what a package is, why it exists, and the trade-offs behind it**, so you can change it with confidence.

## How the pieces fit

```txt
web / native ──▶ api ──▶ Postgres (db)
                   └──▶ object storage
config + env + errors are used by everything
```

The API is the only thing that touches the database and storage. Web and native talk to the API.

## Project rules

- Use the CLI (`pnpm add`, scaffolders) instead of hand-writing what a tool can generate.
- Code lives under `src/`, and every workspace has a README that stays in sync with the code.
- Test new logic, and run `pnpm exec ultracite check` before calling a task done.
- Plan non-trivial work with the System Design Primer, and write the plan down first.
